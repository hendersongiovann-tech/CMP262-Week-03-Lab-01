# CMP 262 – Data Science Programming

## Week 3 – Lab 1: Python Lists and Tuples

Welcome to **CMP 262 – Data Science Programming**.

This lab focuses on Python **lists** and **tuples**. You will practice creating collections, accessing and slicing values, modifying lists, using list methods and built-in functions, looping through collections, packing and unpacking tuples, converting between lists and tuples, and understanding mutable vs. immutable data structures while working in **Jupyter Notebook inside Visual Studio Code**.

## Lab Goal

By completing this lab, you will practice:

- Creating Python lists and tuples
- Accessing values with positive and negative indexes
- Using list and tuple slicing
- Modifying list elements
- Using `append()`, `insert()`, `remove()`, `pop()`, `count()`, and `index()`
- Sorting and reversing lists
- Using `in` and `not in`
- Using `len()`, `min()`, `max()`, and `sum()`
- Looping through lists
- Tuple packing and unpacking
- Converting between lists and tuples
- Understanding mutable and immutable data structures
